# 超导量子设备低温运行仿真系统

一个稀释制冷机低温运行的交互式仿真与可视化页面：把各级温区、制冷能力、线路噪声、
控制脉冲与器件校准关联到同一个带**真实热传递延迟**的物理模型上，演示过快操作引发的
温度反弹、噪声上升与校准失效，并支持从任意检查点派生多种降温策略进行对比。

## 运行

纯静态页面，无需构建：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

（也可直接双击 `index.html`，所有脚本为普通 `<script>`，不依赖网络/CDN。）

## 模型要点（`js/config.js`）

- **五级温区**：室温顶板 / 50K / 4K / Still / MXC；每级有热容 `C`、制冷系数 `g0`
  与制冷机目标温度。制冷抽热按指数松弛积分（半隐式，参数再大也不发散）。
- **级间延迟热流**：相邻级用热导 `G` 与传导 `delay` 相连，热流取上游 **delay 秒前
  的历史温度**（`HistoryBuf` 插值回看）——热交换器的物理延迟使操作效果滞后体现，
  且下游更热时热流自动回流（双向）。
- **制冷阶段**：抽真空 → 脉冲管降温 → 氦冷凝 → 循环运行 → 基温稳定；制冷能力随
  阶段爬坡。每阶段有温区门限 + 保持时间，门限未满足强行推进会触发惩罚热回灌。
- **线路与脉冲**：DC/微波/读取三组线路在各级有寄生/导通热负载并贡献附加噪声；
  脉冲热量按衰减链在 MXC/Still/4K 分级沉积并指数衰减。
- **稳定性**：MXC < 35 mK、Still < 0.95 K、等效噪声 < 520 mK 并保持 120 s；
  失稳有 180 s 迟滞。温度反弹超过 18 mK 告警，超过 30 mK 使校准失效。

## 数据完整性（`js/sensors.js`）

- **迟到 / 乱序数据**：读数带测量时间戳与到达时间，按**水位线**判定迟到，迟到点只
  补绘历史、不回滚当前状态；落入校准窗口的迟到点会下调校准置信度。
- **传感器失效**：失效期间用从失效瞬间复制的独立模型做估计值（虚线显示），该估计器
  的负载快照冻结——期间若操作线路，恢复后真值与估计必然产生偏差。
- **恢复对账**：丢弃失效期积压的在途数据，首个新读数与估计终值对账；偏差按低温绝对
  值（10 mK）/高温相对值（3%）分级，超限则失效期间完成的校准标记存疑作废。

## 检查点与策略（`js/controller.js`）

- 任意时刻可保存检查点并回滚主时间线；从检查点一键派生三种策略离线推演：
  - **标准**：门限满足即推进，进基温后接 DC 线；
  - **激进**：门限提前 60 s 强行推进、脉冲管阶段即接通全部线路，通常因热回灌失败；
  - **保守**：门限后额外等待 240 s、线路最后才接，慢但无反弹。
- 右侧对比表给出总耗时、达基温时刻、基温→稳定时间、最低 MXC、是否反弹，曲线叠加
  各策略的 MXC 轨迹。

## 文件结构

```
index.html        页面结构
styles.css        深色实验台风格样式
js/config.js      温区/阶段/线路/策略参数
js/physics.js     热网络：延迟热流、松弛制冷、脉冲沉积
js/sensors.js     读数噪声、水位线迟到、失效估计、恢复对账
js/controller.js  阶段机、稳定性、校准、检查点、策略分支
js/ui.js          温区图示与三张 Canvas 图表、分支对比
js/main.js        主循环与控件事件
```
