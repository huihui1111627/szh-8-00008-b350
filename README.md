# CryoOps · 超导量子制冷运行控制台

面向超导量子设备低温运行的联动仿真与策略推演界面。把**温区、制冷能力、线路噪声、
控制脉冲、器件稳定性**放在同一个带真实热延迟的模型里：实验人员改变降温阶段、
启停线路、安排校准任务时，状态按热量逐级传导的时间常数更新，过快操作会导致
MXC 温度反弹、噪声升高，并可能让先前校准失效。

纯静态页面（无构建、无外部依赖），直接打开即可运行。

## 启动

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 界面与操作

- **制冷链路（左栏）**：50K → 4K → Still → 冷盘 CP → 混合室 MXC 五级实时温度、
  就绪门限与冷度条；点击任意温区可给该级传感器注入异常。
- **器件稳定性（左栏）**：稳定评分、估计 T₂*、最噪链路、已稳定保持时长、MXC 热负荷。
- **温度/噪声/时间线（中栏）**：对数温度曲线（事件竖线标记）、折算到器件端的
  噪声温度（300mK 门限）、降温/线路/校准甘特图。
- **传输控制**：运行/暂停/单步/快进，三档仿真速度（1、5、30 仿真分钟/秒）。
- **线路与脉冲（右栏）**：四组线路（微波驱动、磁通偏置、读出链路、直流偏置）
  开关与三档脉冲（弱/5min/10min 强脉冲）。
- **校准任务（右栏）**：门参数 / 读出 / 磁通三项校准，有温度门限与稳定保持要求，
  未满足时自动排队；运行中超温或被强脉冲扰动会失效并要求返工。
- **检查点与策略派生（右栏）**：任意时刻保存检查点，从任一检查点一键派生
  标准/保守/激进三种降温策略并离线快进；“从起点对比三策略”给出总耗时、
  稳定时间、反弹次数、校准作废次数、峰值噪声对比表。
- **事件日志**：按全部/告警/传感器过滤，记录策略节点、开关、脉冲、反弹、
  校准、失效、传感器异常与恢复。

## 物理模型要点（`js/model.js`）

- 50K/4K/Still 为线性制冷级（一阶热平衡 + 级间热阻）；冷盘与 MXC 为稀释制冷级，
  制冷功率按 `Pcool = k₀(T²−T₀²)` 建模，基温附近制冷弱，因此数百 nW 的脉冲会
  产生可观测、可恢复的温度反弹。
- 级间耦合在降温期是“冷桥”（下级必须跟随上级降温，形成链式延迟），在稳态只剩
  随温度趋零的微漏热，保证低温平衡不被上级拖累。低温级使用隐式（后向欧拉）积分，
  避免脉冲下的数值刚性振荡。
- 线路热沉积按 5 个温区分别给出（空闲/开启/脉冲三档），噪声温度经各级衰减器加权、
  含量子噪声饱和项与脉冲放大项。
- 校准有硬门限与稳定保持要求；强脉冲（≥70%、≥8min）或校准期间温度显著超门限
  会作废相关校准；就绪需要全部温区达标、全部校准有效、无脉冲并稳定保持 15 分钟。

## 传感器异常与恢复

点击温区注入：

- **迟到数据**：模拟 5 分钟通信延迟，读数先进入“缺口”（图表黄色竖带、面板显示
  采集中并给出真实值对照），到达后按**真实采集时刻**回填，日志标注晚到时长。
- **冻结 / 漂移 / 断线**：面板与曲线相应变黄/置空；故障期间控制不采信该读数。
  恢复后报告与故障期显示值的偏差，并**追溯**故障盲区内的真实温度峰值——若曾越过
  校准门限，相关已完成/进行中的校准一律作废、必须重做，稳定时钟重新计时。

## 三种内置策略的典型结果（同一种子 300K 起点）

| 策略 | 总耗时 | 稳定时间 | 温度反弹 | 校准作废 | 特点 |
|---|---|---|---|---|---|
| 标准 | ~12h55m | 15min | 0 | 0 | 到位后分批上电、紧凑连续校准 |
| 保守 | ~13h53m | 15min | 0 | 0 | 更长稳定保持、仅小幅脉冲验证 |
| 激进 | ~19h40m | ~6h | 1 | 1 | 高温段即上电试脉冲，返工导致更慢 |

“越快不一定越好”：激进策略名义上抢跑，但强脉冲引起温度反弹并作废校准，
返工后总耗时反而最长。

## 文件结构

- `index.html` — 页面骨架
- `styles.css` — 深色控制台样式
- `js/model.js` — 无 DOM 依赖的仿真内核（可在 Node 中直接 `require` 做离线推演/测试）
- `js/charts.js` — 轻量 SVG 图表（温度对数曲线、噪声、甘特时间线）
- `js/app.js` — UI 控制层、回放循环、检查点/策略派生、传感器菜单
